# おんぷよみドリル

ピアノの譜読み練習用のWebアプリです。五線譜にランダムな音符が1つ表示され、ピアノで弾いて答え合わせします。

**公開ページ:** https://onpudrill.vercel.app/

## できること
- ト音記号・ヘ音記号・大譜表の表示
- 出る音の範囲を記号ごとに設定（プリセットあり）
- 音符の種類：全音符、付点2分、2分、付点4分、4分、付点8分、8分、16分
- 臨時記号（♯・♭・♮）と出る割合
- 音名表記：ドレミ / C D E / 両方
- 答え合わせ：自分で○×、またはマイクで音を聞き取って自動判定
- 正解数・連続正解・にがてな音の表示

## メモ
- マイク判定は https で開いたときだけ使えます（初回にマイクの許可が必要）。
- とても低い音はオクターブずれて判定されることがあります。設定の「オクターブまで合わせる」をオフにすると回避できます。
- 設定はブラウザに保存されます。
